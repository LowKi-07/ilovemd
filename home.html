Why 2md

A documentation workspace, not another dev tool

Built for designers, design-system engineers and anyone who needs good documentation without learning Markdown first.

✦

No Markdown knowledge needed

You describe, import or connect. Claude handles the syntax, headings, tables and code blocks.

▮▮

Grounded in your source

Documentation is generated from what is actually in your files. Missing information is marked for review, never invented.

✎

Editable, always

Generated output lands in a split editor with live preview. Review, edit, regenerate — then copy or download the .md file.

📁

Your files stay yours

Local components are read in your browser and only sent for analysis when you explicitly press Generate.

◆

Design-system native

A component documentation template covering anatomy, variants, states, usage, accessibility and design tokens.

↻

Recent documents

Everything you generate is kept locally, so you can come back, refine and re-download any document.

Give it something. Get Markdown back.
